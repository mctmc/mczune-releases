# mczune-releases
A native Windows 11 music player inspired by the Zune desktop experience.

Browse your local collection by artist, album, genre or song. 
Create playlists, save favourites, pin music to Quickplay, and personalise Now Playing with animated artwork and audio-reactive visualisations.

Download and install
Download the latest Setup.exe from Releases, close mczune if it’s running, and run the installer.
- Requires Windows 11 on an Intel or AMD x64 PC.
- Updates retain your library, playlists, and preferences.
- The installer is currently unsigned, so Windows may show an unknown-publisher warning.

About
This repository hosts release downloads. The application source is currently maintained privately.

mczune is an independent project, not affiliated with Microsoft or any music provider. More refinements and features are coming soon.
